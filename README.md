# Rock Paper Scissors Game 🎮

This project is a simple **Rock Paper Scissors web game** built using **HTML, CSS, and JavaScript**.
It allows a player to compete against the computer, where the computer randomly selects Rock, Paper, or Scissors and the game determines the winner based on the classic rules.

This project was created as a **beginner practice project** to learn JavaScript concepts such as **DOM manipulation, event handling, and basic game logic**.

---

## 🚀 Features

* Play Rock, Paper, or Scissors against the computer
* Random computer choice generation
* Instant result display (Win / Lose / Draw)
* Simple and clean user interface
* Lightweight and runs directly in the browser

---

## 🛠️ Technologies Used

* **HTML** – Structure of the web page
* **CSS** – Styling and layout design
* **JavaScript** – Game logic and interactions

## 🎯 Game Rules

* **Rock beats Scissors**
* **Scissors beats Paper**
* **Paper beats Rock**

If both the player and the computer choose the same option, the round ends in a **draw**.
